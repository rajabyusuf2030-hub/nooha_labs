# Nooha Labs Website Project Structure

## Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Folder Architecture
- src/app: route-level pages and global application shell
- src/components/layout: shared layout elements such as navbar and footer
- src/components/sections: homepage and marketing sections
- src/components/ui: reusable UI primitives
- design-system: brand, visual, component, and pattern documentation
