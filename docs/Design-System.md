# Nooha Labs Design System Documentation

## Overview
The design system establishes visual harmony, accessibility, and consistency across Project Atlas and the broader Nooha Labs ecosystem.

## Design Tokens

### Color Palette
- **Primary**: `#2563EB` (Electric Blue)
- **Secondary**: `#06B6D4` (Cyan)
- **Accent**: `#7C3AED` (Purple Glow)
- **Dark Background**: `#020617` (Deep Navy)
- **Dark Surface**: `#0F172A` / `#162033`
- **Light Background**: `#F8FAFC`
- **Light Surface**: `#FFFFFF` / `#F1F5F9`

### Typography
- **Primary Body & Display**: `Plus Jakarta Sans`
- **Code & Monospace**: `JetBrains Mono`

### Spacing & Grid
- Base unit: 8-point grid system (8px, 16px, 24px, 32px, 48px, 64px, 96px).

### Motion & Animation
- Micro-interactions powered by Framer Motion.
- Default duration: 200ms - 300ms easing.

## Component Categories
1. **Buttons**: Primary, Secondary, Outline, Ghost, Link, Loading states.
2. **Cards**: Service, Portfolio, Product, Blog, Team, Stats, Testimonial.
3. **Forms**: Input, Textarea, Select, Checkbox, Radio, Toggle, Search.
4. **Layout**: Navbar, Footer, Section, Container, Grid, Sidebar.
5. **Feedback**: Toast, Modal, Dialog, Alert, LoadingSpinner, EmptyState.
