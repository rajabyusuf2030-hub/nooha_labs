# Changelog — Nooha Labs

## [1.0.0-sprint1] - 2026-07-30
### Added
- Feature-first project architecture (`src/features/`, `src/providers/`, `src/firebase/`, `src/styles/`, `src/types/`).
- Theme System supporting Dark, Light, and System modes with theme switcher.
- Expanded Reusable UI Component Library (`Button`, `Card`, `Input`, `Textarea`, `Select`, `Checkbox`, `Toggle`, `Toast`, `Modal`, `Alert`, `LoadingSpinner`, `EmptyState`).
- Full App Router routes: `/`, `/about`, `/services`, `/products`, `/portfolio`, `/blog`, `/careers`, `/contact`, `/privacy`, `/terms`, `not-found`.
- SEO Foundation: Dynamic metadata generator, OpenGraph cards, Twitter preview cards, sitemap.ts, robots.ts.
- Complete `/docs/` technical documentation suite.
- Firebase integration module in `src/firebase/`.
